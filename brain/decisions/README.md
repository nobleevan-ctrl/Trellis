# Decisions

One file per decision: `YYYY-MM-DD-short-name.md`. Never edit a past decision to reverse it.
Write a new one that names what it supersedes.

```md
# [Decision title]
- Date:
- Owner (final call):
- Status: active | superseded by [file]
- Supersedes: [file or "none"]

## Decision
## Why
## What this changes for agents
```
