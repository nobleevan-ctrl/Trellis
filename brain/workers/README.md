# Workers

Repeatable jobs an agent can run end to end. One file per worker.

```md
# [Worker name]
- Trigger: when/how it runs
- Inputs: what it needs (and which brain files it reads)
- Steps: 1. … 2. …
- Output: exact format and where it goes
- Stop and ask a human when: [ambiguity, missing data, anything risky]
- Reviewer: [person/role]
```
